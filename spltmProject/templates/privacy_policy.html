Privacy Policy

Effective Date: February 11, 2026

SplitMoney ("Platform", "we", "our", or "us") operates a money-sharing event platform that enables users to create events, invite participants, collect contributions, and manage vendor payments under an Admin-controlled settlement system.

Important: Participant payments are collected into the Platform’s designated Admin account. Organizer wallets are display-only views. Vendor payouts are processed by Admin after event completion.

1. Platform Overview

SplitMoney allows Organizers to create shared-cost events (such as trips, turf bookings, restaurant bills, or celebrations), invite Participants, collect contributions, and request vendor settlement. The Platform acts as an intermediary administrator managing payment collection and vendor disbursement.

2. Information We Collect

A. Account & Authentication Data

  • Full name
  • Email address
  • Mobile number
  • Password hash
  • OTP/email verification status
  • Profile image (optional)

B. Event & Participation Data

  • Event title, description, category
  • Date, time, and location
  • Vendor details
  • Invited participant list
  • Invite status and payment status

C. Payment & Financial Data

  • Transaction amount
  • Payment method (UPI, Card, Net Banking, Wallet)
  • Gateway order ID
  • Gateway payment ID
  • Payment timestamps
  • Payment status (Success / Failed / Pending)

We do not store full debit/credit card details. Payment processing is handled securely by third-party payment gateways.

D. Vendor & Payout Information

  • Vendor name
  • UPI ID or Bank account details (when applicable)
  • Payout status and reference ID

E. System & Audit Logs

  • Login activity
  • Event updates
  • Payment verifications
  • Administrative overrides

3. How We Use Your Information

  • To create and manage events
  • To process participant payments
  • To maintain Organizer wallet display views
  • To process vendor payouts after event completion
  • To detect fraud and prevent misuse
  • To generate financial and audit reports
  • To comply with regulatory and legal requirements

4. Payment Flow Transparency

The Platform operates under the following structured financial workflow:

  • Participant pays → Amount credited to Admin-controlled account
  • Organizer wallet reflects collected amount (display only)
  • Event marked completed → Organizer requests payout
  • Admin verifies and releases payment to Vendor

SplitMoney does not function as a banking institution. Funds are administered according to the platform’s event lifecycle rules.

5. Data Sharing & Disclosure

  • With payment gateways for transaction processing
  • With banking institutions for payout processing
  • With law enforcement if legally required
  • With users (limited to event-related information only)

We do not sell personal data for marketing purposes.

6. Data Retention

We retain transaction records, payout logs, and audit trails as required for financial reconciliation, compliance obligations, dispute resolution, and reporting.

7. Security Measures

We implement administrative, technical, and operational safeguards including:

  • Encrypted payment gateway integration
  • Role-based access control (Admin/User separation)
  • Secure password hashing
  • Audit logs for financial operations

8. User Rights

  • Access and update profile information
  • Request account deactivation (subject to financial record retention)
  • Request clarification regarding stored personal data

9. Children’s Privacy

SplitMoney is not intended for users under the age of 13. We do not knowingly collect data from minors.
